Linked signers

Compare a code, then grant a scope. A request does not sign by itself.

Six digits, both sides

Pair Passport with a Hub, or with another signer, by comparing a six-digit code. Compare it before either side grants anything. Each participant keeps its own key.

A grant is a scope

A grant names the other signer and the scopes it covers, such as message. The grant is not a signature on a later request. What the grant allows is decided by signer rules, on the last page of this path.

Check it

examples/delegation-body.js in @fabric/http puts a fabric: grant in a JSON body, reads it back, and then refuses the next call once the rate limit is spent. No socket is opened.

node examples/delegation-body.js
