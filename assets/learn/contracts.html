Application resource contracts

Gossip moves bytes. A contract is the agreement those bytes refer to.

The same envelopes

An application resource contract is not a new family of wire types. Three public messages carry it.

  • CONTRACT_PUBLISH is the genesis.
  • CONTRACT_MESSAGE is an event inside that namespace. The body names the contract.
  • CONTRACT_PROPOSAL batches messages, with a Merkle root, a JSON patch, and an optional PSBT.

Names such as GroupChat live in the body. They are not outer opcodes.

The first page sets the rules

A genesis names which message types are in bounds, who may read, who may sign, and the threshold, how the tip maps to a Bitcoin Taproot output, and a Bitcoin block hash that ties publication to the chain. An empty list of message types denies every body.

First writer wins

The namespace id comes from that genesis. A second signed genesis for the same id is a different envelope. The register keeps the first.

Same bytes, same fold

Publishers and participants ingest the same signed frame, from the mesh or as a fabric: string. Fold order is the message hash, so arrival order does not pick the winner. That is why a relay has to forward the original bytes. A rewritten frame would make honest copies of the contract diverge.

A peer can still flood a CONTRACT_MESSAGE for a namespace it has never opened. Applications ignore ids they do not keep.

A valid envelope is not enough

Anyone can gossip a frame. Changing membership or the spend policy requires the author to already be a signer, or to present a verified sign token for this contract. Chat under the contract is for its readers and signers. It is not the public shoutbox.

A withdrawal has to cite the tip's state digest and the Bitcoin block hash it claims. A stale binding is refused. A local program run is a commitment to a computation. It does not, by itself, change the Taproot address.

Where to check the envelope

These frames ride the gossip path. The tutorial runner checks a signed envelope, not a full contract fold. That check is examples/fabric-basic-usage.js in @fabric/core.
