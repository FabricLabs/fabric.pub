Protocol walkthroughs

First pictures of the local stack. The scripts are the check.

A reading path through the local stack. Gossip is how bytes move. The rest is what rides it, who holds the keys, and where HTTP and the Hub sit.

Each page below names the offline script that checks it. Run those from a clone of @fabric/core, @fabric/http, or Fabric Hub.

  1. 01 How peers talk Peers on different computers, carrying signed messages for each other.
  2. 02 Application resource contracts Gossip moves bytes. A contract is the agreement those bytes refer to.
  3. 03 Message bodies The header says who signed. The body says what they said.
  4. 04 Directed forward One next hop at a time, when the square should not hear it.
  5. 05 Three keys from one seed The master derives. Applications sign with the children.
  6. 06 Passport sign-in Your key answers a challenge from the site your browser is actually on.
  7. 07 Linked signers Compare a code, then grant a scope. A request does not sign by itself.
  8. 08 Named federations A descriptor, a threshold, and a vault every member can derive.
  9. 09 Sidechain and Beacon A document with a clock, and one string for the epoch.
  10. 10 The HTTP and Hub edge JSON at the door. The protocol stays on the other side of it.

Run the checks

Each repository has scripts/example-tutorials.js. Every script exits on its own. None of them open a port, and none of them start Bitcoin or Lightning. The repositories require Node.js 26.13.0.

@fabric/core

npm run example:tutorials signs and verifies one chat message, peels a directed forward, builds a collection plus one message, and does an in-memory get and set.

@fabric/http

npm run example:tutorials issues a Passport challenge and redeems it once, translates a ping and a sidechain patch, and reads a fabric: grant from a request body.

Fabric Hub

node scripts/example-tutorials.js checks the operator keys, the signer rules, the two vault addresses, the document markup, and the wire catalog.

npm run example:tutorials
