Three keys from one seed

The master derives. Applications sign with the children.

Identity, wallet, cosigner

One seed becomes three keys: a Fabric identity, a Bitcoin wallet, and a BIP87 cosigner. The public keys differ. A signature from one cannot be checked as another.

The Hub uses the same split

A Hub's root key only derives. Account 0 on the Hub's network yields an identity, for messages and attestations, and a cosigner, for federations and the Beacon. The root public key is a third value. It is not either of those signers.

examples/operator-keys.js in the Fabric Hub repository checks that split on regtest. The words exist only in memory.
